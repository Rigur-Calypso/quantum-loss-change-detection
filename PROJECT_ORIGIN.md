# Project provenance

This independent implementation continued from an existing local SOP project.
Original local folders and historical results were retained. This repository is
a publication copy prepared for GitHub, rather than the authors' official code.

Copied metadata uses relative working paths. Publication migration records
identify original and updated checksums without exposing personal local paths.
Our scientific arrays and numerical tables retain their original bytes.
The early project README is retained in docs/history/README.md; later validation
and the current scope are in README.md, FINDINGS.md and release/VALIDATION.md.

The implementation was developed with AI coding assistance and validated using
the tests and independently checked calculations described in those documents.
